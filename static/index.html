How it works

Upload a CSV file with a subscriber ID and an IGM version for each customer. The organisation is found from the subscriber ID in the built-in sample environment access data, then a fake create-token call is made. No server, database or real API is used. You get the CSV back with org_id, status and message filled in.

Upload your customer CSV

Limit: up to rows per file; any rows after that are left untouched so you can upload them in the next file.
